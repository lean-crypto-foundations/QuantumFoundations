# QuantumFoundations

Finite-dimensional quantum information for cryptographic proofs in Lean 4, on Mathlib only.
Shared by [CatCrypt](https://github.com/spitters/CatCrypt-core) and
[VCVio](https://github.com/Verified-zkEVM/VCVio). Lean v4.35.0, Mathlib v4.35.0; a release tag
per Lean version.

CI builds the library and fails on any axiom other than `propext`, `Classical.choice` and
`Quot.sound`.
